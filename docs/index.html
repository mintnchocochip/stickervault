The problem

Four years. Four phones. Four collections rebuilt from nothing, because the only copy lived inside an app that dies with the handset.

How it works

Take the collection out. Put back what you want.

01

Archive

Grant the sticker folder once. Everything is de-duplicated by content hash and streamed into a single zip in Downloads — as a foreground service, so it survives leaving the app.

02

Keep

The zip holds plain WebP files that open on any computer. No proprietary container, no database, nothing that needs this app to read it. Put it on Drive and forget it.

03

Restore

On the new phone, point the app at the zip. Stickers are verified, regrouped into their original packs, and handed to WhatsApp.

Under the hood

The interesting parts.

Pack names survive without root

Every WhatsApp sticker carries an EXIF chunk naming the pack it came from. 94.9% of a real library had it — enough to rebuild 433 packs, plus 783 self-made stickers, with the database WhatsApp keeps locked away never touched.

The filename is the checksum

Files are stored under their own SHA-256. A sticker whose bytes do not hash to its own name is corrupt or tampered with, and is refused on import. Integrity comes free from the layout, with no checksum file to keep in sync.

It physically cannot phone home

No INTERNET permission is declared, so the OS blocks any network call regardless of what the code does. No storage permission either — folder access is a user grant, not a capability.

Archives are treated as hostile

A strict entry-name allowlist, control-character rejection, zip-bomb ceilings, and a real-WebP check before anything is written. Declared sizes are never trusted. Thirty-four traversal and encoding payloads are tested against the rule.

Honestly

What it can't do.

Uninstalling removes the packs

WhatsApp serves third-party packs live from the providing app rather than copying them in. That is true of every sticker app on Android, and has been an open request since 2018. The zip is the durable artifact; the app is a replaceable adapter.

WhatsApp caps packs per app

The documented limit is ten packs, around 300 stickers. Whether it is actually enforced at runtime is still unverified — the app asks WhatsApp directly and shows you which packs it kept.

Large animated stickers are archive-only

Android ships no animated-WebP encoder, so an animated sticker over WhatsApp's 500 KB limit can be stored safely but never shrunk to fit. Those are reported, not silently dropped.
